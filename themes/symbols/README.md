# Lumen symbols

UI glyphs used throughout LUMEN OS. They are a curated subset of
[Phosphor Icons](https://phosphoricons.com) 2.1.1 (MIT, see
`LICENSE.phosphor`) in three weights: `regular`, `bold` and `fill`. Every SVG
uses `fill="currentColor"`, which `Lumen.Design`'s `Symbol` item replaces with
the requested color at render time.
